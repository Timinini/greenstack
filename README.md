# GreenStack Contract

A sustainability-focused contract that incentivizes environmentally friendly
actions by issuing rewards and tracking green contributions on-chain.

## Key Functions
- `record-contribution` — Log verified green activity
- `mint-reward` — Issue sustainability incentive tokens
- `claim-reward` — Allow users to claim earned rewards
- `set-reward-rate` — Configure incentive distribution parameters
- `get-contribution` — Retrieve user sustainability records

Designed for climate DAOs, carbon initiatives, and eco-incentive DeFi systems.
